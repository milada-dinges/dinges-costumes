# Костюмерная Дингес

Сайт проката карнавальных костюмов и ростовых кукол в Барнауле.

**Сайт:** https://dinges-costumes.netlify.app

## Что умеет сайт

- Каталог костюмов с фильтрами: категория, подкатегория, размер, пол
- Корзина: выбор костюмов, дня, времени и срока аренды, готовое сообщение для заказа
- Админ-панель с входом: добавление и удаление костюмов, загрузка фото
- Адаптивная вёрстка под телефон, планшет и компьютер

## Технологии

React, TypeScript, Next.js, Zustand, Supabase (PostgreSQL, вход, хранилище картинок), CSS
